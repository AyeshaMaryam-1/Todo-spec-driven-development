# Frontend Page & Component Development

## Instructions

1. **Page structure**
   - Semantic HTML structure
   - Clear sectioning (header, main, footer)
   - Consistent spacing and alignment

2. **Components**
   - Reusable UI components (buttons, cards, navbar)
   - Props-based or class-based variations
   - Separation of concerns (structure vs styling)

3. **Layout system**
   - Flexbox and Grid for layout
   - Responsive breakpoints
   - Mobile-first design approach

4. **Styling**
   - Clean and consistent color palette
   - Typography hierarchy (headings, body text)
   - Utility-first or component-based CSS
   - Hover and focus states

## Best Practices
- Use semantic HTML for accessibility
- Keep components reusable and modular
- Avoid inline styles
- Follow mobile-first responsive design
- Maintain consistent spacing and typography

## Example Structure
```html
<main class="page-container">
  <header class="navbar">
    <h1 class="logo">Brand</h1>
    <nav class="nav-links">
      <a href="#">Home</a>
      <a href="#">About</a>
      <a href="#">Contact</a>
    </nav>
  </header>

  <section class="content">
    <div class="card">
      <h2>Component Title</h2>
      <p>Reusable component content goes here.</p>
      <button class="btn-primary">Learn More</button>
    </div>
  </section>
</main>
